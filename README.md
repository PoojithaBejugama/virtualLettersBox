# virtualLettersBox

A romantic, rustic “Open When” letter-box experience built with Next.js.

## Run locally

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Production build

```bash
npm run build
npm start
```

The current version is a front-end prototype. Account creation, persistent letters, owner approvals, and private recipient access still need a backend and authentication provider.
